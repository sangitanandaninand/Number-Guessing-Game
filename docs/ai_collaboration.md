# AI Collaboration

## Purpose

This document describes how AI was used during development and how the collaboration with AI helped shape the project.

## What AI Helped With

- Generating initial C++ code structure for game logic.
- Suggesting validation patterns for user input and error handling.
- Recommending design ideas for separating responsibilities between classes.
- Drafting documentation and reflections on the project.

## How AI Was Used

- AI was asked to suggest implementations for game loop behavior, hint support, and leaderboard updates.
- Generated code was reviewed manually and adjusted to fit the existing project style.
- AI assistance was treated as a helper for repetitive tasks and syntax reminders rather than a final solution.

## Review Process

- All AI-generated code was checked for correctness before being accepted.
- Logic was tested mentally and through compilation whenever possible.
- Unnecessary or incorrect AI suggestions were removed or rewritten.

## Lessons Learned from AI Collaboration

- AI can accelerate boilerplate code creation and provide useful examples quickly.
- It is important to keep the final implementation under developer control.
- Reviewing AI output for edge cases and integration issues is essential.

## Future AI Use

- Continue using AI for drafting code snippets, tests, and documentation.
- Use AI as a brainstorming partner for feature ideas and refactoring suggestions.
- Keep improving the review workflow so AI contributions remain reliable and maintainable.
